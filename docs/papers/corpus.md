# The AI-papers corpus

The papers PaperPlay teaches first (ADR-0052): 34, each as arXiv gives it, written by `npm run corpus` from arXiv's API and OAI-PMH records. The groups are the owner's, kept as given; the plan, `docs/design/ai-papers.md`, decides each paper's family.

Licence: 25 of 34 keep their text, so a world quotes them in anchors and short quotes only and never keeps it: arXiv's non-exclusive licence, and 2503.13657's CC BY-NC-ND 4.0, which forbids derivatives. 9 are under an open licence (2201.11903, CC BY 4.0; 2210.03629, CC BY 4.0; 2303.11366, CC BY 4.0; 2305.14325, CC BY 4.0; 2305.10601, CC BY 4.0; 2308.08155, CC BY 4.0; 2405.15793, CC BY 4.0; 2407.01489, CC BY 4.0; 2310.01798, CC BY 4.0). LaTeX source: 34 of 34 on arXiv.
