### The capture across runtimes: a finding

CI's capture job on `main` (run 37967849151) filmed the same code, with the same Chromium
(153.0.8010.12), SwiftShader and Node, on Linux x86-64. The hashes differ from the Mac's:

```
Linux  1080x1350  frames 420a0e42db0a…  video cf7dcb676cc7…
Linux  1920x1080  frames 64d3b6bd8ebc…  video d1946b8dd1c5…
Mac    1080x1350  frames 53e7bd491d18…  video bb8455fbf5e5…
Mac    1920x1080  frames 3f9efb368493…  video 56c7f73b55f9…
```

A second Linux run (run 37969019227, dispatched by hand) matched the first byte for byte:

```
captures/murmuration-1080x1350.webm linux run1 vs run2 frames same: True video same: True 420a0e42db0a cf7dcb676cc7
captures/murmuration-1920x1080.webm linux run1 vs run2 frames same: True video same: True 64d3b6bd8ebc d1946b8dd1c5
```

Frames decoded from both 1920 × 1080 videos and compared in the browser. The bird pixels are
those with luminance below 90:

```
t=0.0s {"meanAbs":0.135,"max":19,"over8Pct":0.003,"birdPixelsMac":8224,"birdPixelsLinux":8203,"birdOverlap":0.993}
t=7.5s {"meanAbs":0.227,"max":19,"over8Pct":0.065,"birdPixelsMac":8986,"birdPixelsLinux":8966,"birdOverlap":0.996}
t=14.9s {"meanAbs":0.199,"max":16,"over8Pct":0.047,"birdPixelsMac":7753,"birdPixelsLinux":7729,"birdOverlap":0.995}
```

**Reading:**
- The capture is byte-identical per runtime, not across runtimes.
- The difference is in the drawing, not the run. A chaotic flock whose run had diverged
  would not overlap 99.5% after 15 s.
- The likeliest cause is SwiftShader's code generation on arm64 against x86-64. Comparing
  the lossless PNG frames would tell drawing from JPEG encoding, but that was not done.

**Per the owner's rule:**
- no test was loosened;
- the finding is recorded here;
- `architecture.md` now has "Claims per runtime";
- work stopped to report it.

## Problems and how they were solved

- **axe flagged the quiet origin tags,** with sub text on aqua at 3.2:1. The cause was a
  class-name collision: `/world/local`'s global `.quiet { color: sub }` beat the tag's ink.
  The modifiers are now `origin-tag-quiet` and `origin-tag-placeholder`. Listing the rules
  that matched the element found it.
- **TypeScript did not carry a module-level narrowing into the component** (`action` after
  `if (!action) throw`). Its default value is now a module constant.
- **A test file restored from the spike's tag was not registered as read,** so the first
  write was refused and the old tests ran against the new guide. It was read, then written.

- **CI's first run failed `check:docs`.** `progress.md` named the spike's commit, which only
  a local tag reached. Pushing the tag fixed it. The docs on `main` point at that commit, so
  the tag belongs on `origin` anyway.
