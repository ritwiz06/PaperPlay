# Session 2026-10-14: the model provider, Threshold Town's fixes, then G3a.3

## Goal

The owner answered the last session's questions and asked for four things, each on short
branches landed through `npm run land`.

**The model provider is ASU Research Computing's Voyager gateway** (ADR-0030, superseding the
Anthropic SDK). Acceptance, in plain language:
- the key lives only in `apps/api/.env`, which `.gitignore` covers; git's history never held it;
  the bundle secret check knows its format; nothing prints it;
- one adapter, with per-stage model ids, timeouts, retries with backoff, a rate limit and a
  per-job token budget in the job's trace;
- every model call recorded; tests and CI replay recordings, and only `npm run pipeline:live`
  calls the gateway;
- a probe of each candidate model's structured output, with a fallback of plain JSON, Zod and
  one retry; models marked "Testing in progress" skipped;
- the static build never holds the key, the API or a working `/create`.

**Threshold Town's fixes** (ADR-0029 accepted with them): ill figures warm orange and removed
figures soft blue-grey; "recovered or removed" at Beginner; level 1's values leaving 20 to 40% of
the town still well, with the level rule re-run; a labelled three-part readout with counts;
"You said" for the learner's own prediction, with no origin chip; the fork chart's axis fitting
the population; the town framed closer on a phone.

**G3a.3, the pipeline on the compartment family:**
1. gold ModelSpecs by hand for three CC BY compartment-model papers (arXiv q-bio and PubMed

## Problems and how they were solved

- **Land refused `g3/transcribe` twice at its local gate, nothing pushed:** unrelated tests (the
  flock oracles, the fork test, the stage's first frame) timed out, every test 3 to 5 times slower
  than in the ingest land half an hour before. The first time I had run two Vitest files beside
  the gate; the second time nothing ran beside it. The Mac was on battery at 1%, in Low Power
  Mode. Once on power, I landed again with the machine idle. I now run nothing beside a land's
  local gate.

- **Land refused `g3/ingest` at its local gate:** a fake network in the ingest test handed back a
  gzip `Buffer`'s `.slice().buffer`. A Node `Buffer` may share a pooled block, so the fake returned
  the wrong bytes there and gunzip failed ("incorrect header check"); in my worktree it passed by
  luck. The fake now copies the bytes. Nothing had been pushed.

- **Land refused `g3/model-adapter` on red CI** (run 38606652575 on `3f3f030`). The live client's
  refusal was right; my test was not. Under CI the refusal names CI first, and the test accepted
  only the test runner's message. It now accepts either, and passes with `CI` set and without.
  Separately, I first told the owner the land had succeeded, from the background job's exit code;
  that was the wrapper's `echo`, not land's. I corrected it on reading the log, and now read land's
  own last line before reporting.

- **The key was at the repository's root,** in a `.env` that `.gitignore` already covered. It
  moved to `apps/api/.env`.
