# Session 2026-10-14: the model provider, Threshold Town's fixes, then G3a.3

## Goal

The owner answered the last session's questions and asked for four things, each on short
branches landed through `npm run land`.

**The model provider is ASU Research Computing's Voyager gateway** (ADR-0030, superseding the
Anthropic SDK). Acceptance, in plain language:
- the key lives only in `apps/api/.env`, which `.gitignore` covers; git's history never held it;
  the bundle secret check knows its format; nothing prints it;
- one adapter, with per-stage model ids, timeouts, retries with backoff, a rate limit and a
  per-job token budget in the job's trace;
- every model call recorded; tests and CI replay recordings, and only `npm run pipeline:live`
  calls the gateway;
- a probe of each candidate model's structured output, with a fallback of plain JSON, Zod and
  one retry; models marked "Testing in progress" skipped;
- the static build never holds the key, the API or a working `/create`.

**Threshold Town's fixes** (ADR-0029 accepted with them): ill figures warm orange and removed
figures soft blue-grey; "recovered or removed" at Beginner; level 1's values leaving 20 to 40% of
the town still well, with the level rule re-run; a labelled three-part readout with counts;
"You said" for the learner's own prediction, with no origin chip; the fork chart's axis fitting
the population; the town framed closer on a phone.

**G3a.3, the pipeline on the compartment family:**
1. gold ModelSpecs by hand for three CC BY compartment-model papers (arXiv q-bio and PubMed
   Central, at least one of each), and a bake-off of the gateway's models per stage, scored
   against them, recorded in `eval/models.md`;
2. `apps/api`: jobs, honest SSE states (R11), JSON artifacts, upload limits, the sanitiser with
   its log (R09);
3. ingest: arXiv LaTeX source, PubMed Central by a supported route, PDF text; each licence in the
   source register;
4. the pipeline: Reader, two independent transcriptions matched structurally, Planner, Explainer,
   the builder, the level-rule sweep, the checks, a Reviewer that cannot overturn a check (R10),
   and a Controller with at most two scoped repairs;
5. `/create`, local only, with real job states and exact failures;
6. the first generated world, from one of the three papers, end to end, with real anchors.

## Decisions made and needed

**Made by the owner:** Voyager as the provider, and everything ADR-0030 lists but the adapter's
form; ADR-0029 accepted with its fixes.

**Made by me:**
- **The adapter is plain `fetch`,** not the `openai` package (ADR-0030).
- **The secret check runs inside `npm run build`,** so the deploy fails on a leak as the gate does.
- **Threshold Town's fixes (ADR-0029's amendment):** the ground and plaza darkened so the new
  colours keep 3:1; the readout's own row on a town's card; level 1's rate and 200-day time;
  "learner" as a guide line's origin; the fixture's source in the repository.
- **The adapter (ADR-0030):** recordings hold the prompt's hash, never the prompt, so no paper's
  text is stored with them; a live client is made only under `npm run pipeline:live`, checked by
  npm's own `npm_lifecycle_event`, which works on Windows as on the Mac.
- **Needed from the owner:** which models the Voyager portal marks "Testing in progress". The API
  does not say, so no model is chosen for a stage until the owner names them.
- **For the owner:** CLAUDE.md's design floor lists the palette; it now has two more colours,
  `ember` and `mist`, for the town's figures. I left CLAUDE.md as it is, since it is yours.
