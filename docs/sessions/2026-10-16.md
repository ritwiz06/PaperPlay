## Decisions made and needed

- **The thinking model by its own name:** the gateway lists `qwen3-235b-a22b` as a family whose
  thinking setting is `qwen3-235b-a22b-thinking-2507`; that name answers and honours a schema, so
  it is the candidate, as the owner named it (ADR-0035's amendment).
- **One bake-off run, after the prompt changes:** value sets, findings, visibility and units each
  change a stage's prompt, which voids its recordings; running the bake-off before them would
  have been thrown away. Interim picks come from the current tables until then.
- **Prompt changes land together, with that run.** A branch that changed a prompt alone would fail
  the gate, its replay tests finding no recordings. So the value sets' machinery lands first with
  the transcriber's request unchanged, the deterministic rules next, then one branch with every
  prompt change and the bake-off (ADR-0036, item 6).
- **The tuberculosis paper's pick is its Ethiopian fit,** by the owner's rule: "The simulations are
  performed by using the set of parameter values given in Table [tab:6.2]", and its results
  section is about the Ethiopian data. The gold said the synthetic set before; it now lists both.
- **Needed from the owner: the hepatitis C paper's headline does not hold at its own values.** By
  its equation (7) at its Table 1, the reproduction number is 0.76 at the table's adherence and
  0.65 to 0.78 across every adherence, never above 1; the 52% threshold of its abstract and Figure 7
  must rest on values it does not state. Under the rule that the hook tests the headline, no level 1
  is both visible and more than definitional unless it takes full adherence and measures the
  acutely infected, which no planner round tried. Options: let the hook test the headline's
  direction with the threshold's absence said on screen as a computed observation; let it fall to
  the first anchored finding the model shows, saying why; or keep the rule, and the paper makes no
  world (ADR-0037's amendment).
- **Needed from the owner: how many levels a plan holds.** The tuberculosis plan held three, the
  fewest a world keeps, so one level that failed its repair ended the job. Asking for five, as the
  owner's "three of five" suggests, would let a failing level be dropped.
- **The planner pick, by a corrected tie-break:** glm-5-3 and qwen36-27b tie on every key the rule
  names; glm-5-3's planner failed on one paper of three, and the report had counted only other
  stages' failures. A stage's own failed calls now break the tie, and qwen36-27b is picked
  (ADR-0035's third amendment). The reviewer, gemma4-31b-it, is now another model than the
  planner.
- **The first generated world keeps its path:** with no regenerated world, it was not renamed.
- **A PDF's pages are its sections, and an equation it draws is refused, not guessed** (ADR-0038):
  an anchor names its page; a matrix of bracket glyphs, glyphs with no text, or a fraction split
  over lines is named in the job's events with its page and reason. A PDF from this machine has
  its licence `unknown`, so its text is never kept in the repository.

## Problems and how they were solved

- **The stage core may import no runtime code from contracts,** a boundary the lint enforces, so
  the town's figure count could not move into contracts for the pipeline to share. It stays in the
  stage core; the pipeline keeps a copy, and a tooling test holds the two equal over a thousand
  random cases.
- **The first world's replay test fails under the visibility rule,** as it should: its level 5,
  "Re-susceptibility barely matters", shows nothing. The test is retired and the world kept, tested
  as made; the regenerated world's job takes its place.
- **My mistake: the owner's email in a request header.** Downloading the hepatitis C paper's PDF
  from journals.plos.org, I put the owner's email address in the request's User-Agent. That sends
  it to a service the owner did not choose, and cannot be taken back. Later requests carry none.
- **Land refused `g3/lessons` at its local gate, nothing pushed:** the web app's typecheck reached
  `node:crypto`. The pipeline's root exports the findings check, whose type imports from the
  planner and reader stages pulled in the model client, and the web app has no Node types. I had
  typechecked the pipeline alone. The check now names the shapes it reads.
- **pdfjs 6 changed its API:** `isEvalSupported` is gone and a document is released through its
  loading task; the reader follows the types of the version installed.
- **A recovered equation must be the text its span holds,** as `SourceText` requires; the PDF reader
  writes each recovered equation into the page's text as recovered, so anchors quote what is
  stored.
- **The reviewer's limit:** at 8,000 tokens qwen thought and wrote nothing; the reviewer now has
  32,000, like the planner.
- **Three fork tests timed out on their first frame** with three spec files running at once; all
  ten passed run alone.
- **The gate failed twice on `g3/pdf-ingest` in the browser tests alone,** 22 and then 13 tests
  waiting more than 5 seconds for a first frame, while my capture browser ran beside it and the
  machine's load stood near 30; on a quiet machine it passed, and so did land's.
- **The tuberculosis job stopped on a capital letter,** a quote of "Exposed individuals …" where the
  paper reads "Thus, exposed individuals …"; its repair returned the same quote. The quote finder
  now folds the first letter's case (ADR-0032's amendment), and the bake-off was rescored.
- **qwen36-27b's explainer wrote "to fast treatment" where `{to}` goes,** twice, failing the
  tuberculosis job; the mend now reads a value named in a few words. Re-run, the job replayed to
  that point and went on.
- **The first generated world's guide read "You raise treatment adherence to , so",** in the
  before screenshot too: the model wrote "to {to}", and at Beginner the shell drops the number. The
  shell now reads a written "to" before `{to}` as the value's own.
- **My mistake: waiting loops that waited on themselves.** I waited for `design-v3` with
  `pgrep -f "pipeline-live.ts design"`, which matches the waiting shell's own command line, so the
  loops ran half an hour after the run had ended at 17:19.
- **The dev server kept a deleted world in its file glob** after I renamed the first world and put
  it back; restarting it fixed the page.
