## Problems and how they were solved

- **The first capture hung.**
  - **Cause:** Playwright's ffmpeg build has no `-` input protocol ("Protocol not found. Did
    you mean file:fd:?"), so it exited at once. The script then waited forever for a `drain`
    on a pipe that nothing was reading.
  - **Fixes:**
    - Stdin is `pipe:0`, as Playwright itself names it. The test was changed first and
      failed red.
    - Before each write, the script checks whether ffmpeg has exited, and races the drain
      against ffmpeg closing. An early exit now fails at once, with ffmpeg's own message.
- **The build has no `select` filter,** so sample frames were pulled out by seeking (`-ss`)
  instead.
- **macOS has no `timeout` command,** so the planted-encoder run was bounded with
  `perl -e 'alarm 120; exec @ARGV'`.

- **The first gate run on the axe branch failed in lint,** with 18 `no-unsafe-*` errors in
  the new spec.
  - **Cause:** `@axe-core/playwright` ships CommonJS typings. Under NodeNext, its default
    import is the whole module, not the class.
  - **Fix:** the named import `{ AxeBuilder }`. The package exports it too.
  - **A gap behind it:** `npm run typecheck` never covered `tests/e2e`. Only lint saw the
    error, and Playwright's own loader ran the test anyway. The browser tests are now in
    the typecheck. The existing specs were already clean.

- **The shell's default Node is 22.23.1.** Every check ran through
  `fnm exec --using=24.21.0`, so the gate's runtime check accepted the evidence.
