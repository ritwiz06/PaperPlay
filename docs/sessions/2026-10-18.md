  grant interactively (`gh auth refresh -h github.com -s user`); the repository's own job durations,
  rounded up per job, give about 2,082 minutes from 1 to 18 October, against GitHub Free's 2,000.

- **The hepatitis C job failed on a repair:** kimi-k2-7-code thought until its 32,000 tokens and wrote
  nothing, and the reply it was asked to correct had two goals over 160 characters, so the job
  stopped. The explainer had met the first of these on 2026-10-17; the planner's repair now gets
  twice the room in that case, and a repair that cannot be read leaves the plan as it was, spending
  the repair, so the rules drop what it was to mend, as boundary 5 says (`b9233ce`). The bake-off
  makes no repairs, so its recordings replay unchanged; three of its first plans did run out of room
  and are corrected as before.
- **The second run stopped with too few levels:** a reviewer blocked level 3's What-if question,
  "the paper's 0.19" for a threshold the paper derives, twice; the explainer's reword could change
  only the goal and the effect, so the block could never be met, and dropping the level left too few.
  The reword now writes every sentence of the plan's a learner reads (`bf8ff02`).
- **Recordings no test reads:** 493 tracked recordings, from prompts since changed, are read by no
  replay; they stay as the record of the runs that made them.
- **The bake-off in the second worktree** needed `apps/api/.env`, which is git-ignored; it is a link to
  the main worktree's, so the key is in one file still.
