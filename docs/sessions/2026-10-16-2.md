## Goal

The owner answered the two decisions of the session before and set two rules, then asked for the
regenerations and a plan, on short branches landed through `npm run land`:

1. **Two rules for CLAUDE.md:** no personal data in any outbound request unless the owner opted in,
   through `PAPERPLAY_CONTACT_EMAIL`, unset by default, with a test; land refuses while a live job
   runs, live jobs and gates never share the machine, and the first-frame timeouts are not loosened.
2. **Decision 1, a reproducibility check:** a deterministic stage with no model call that
   recomputes the headline quantity from the transcribed equations (for R0, the next-generation
   matrix through our own code) and compares it with the paper's own formula at the same values,
   checks every value's units against the model's time unit, and scans captions, methods and
   supplementary text for other value sets behind the headline figure. Only if all of that
   confirms the mismatch does level 1 test the headline's direction, saying so neutrally as a
   computed observation; a journal page, "Running the paper's own numbers", shows the check's table.
   If even the direction does not show, the first anchored finding the model shows, saying why. A
   mistake of ours found by the check is fixed and recorded as a finding about the pipeline.
3. **Decision 2, five levels:** the planner asks for five; a world keeps at least three; the hook is
   never dropped; any other level that fails its repair is dropped, the reason in the job; in a
   repair the planner sees its control's row of the response table.
4. **The hepatitis C world regenerated and the tuberculosis paper re-run** as recorded jobs, with
   the reproducibility check's table for hepatitis C, and why the independent R0 and the paper's
   formula agree or differ.
5. **G3a's close-out** in the roadmap, with a short summary.
6. **A plan for G3b,** docs only, `docs/design/g3b.md`.

## Decisions made and needed

- **The locks live in the git directory,** not in the home directory or the system's temporary one:
  every worktree of the repository shares it, which is where gates and live jobs run, and nothing is
  written outside the repository (ADR-0039).
- **`pipeline:live serve` holds its lock while it runs, idle or not:** a server that can start a
  live job at any moment counts as running one, so land waits for it to be stopped.
